# Crew Connectivity Guide (all vessels)

Meridian Marine Services IT, version 3.2.

## Crew Wi-Fi

- Network name: MMS-CREW. Officers and ratings use the same network.
- Each crew member gets a personal data allowance of 3 GB per calendar month, reset on the 1st at 00:00 UTC.
- Access vouchers are issued by the Master or the Chief Officer. One voucher works on up to 2 devices.
- Video streaming is blocked between 08:00 and 18:00 ship time to protect bandwidth for operations.
- When the allowance is used up, speed drops to 128 kbps until the next reset. Messaging apps still work.

## Personal devices

- Personal laptops and phones may only join MMS-CREW, never the ship's business network (MMS-OPS).
- USB drives must not be connected to any ship computer. This is a cyber-security rule (ISM cyber annex).
- Devices must run an operating system that still receives security updates.

## Passwords

- Ship email and crew portal passwords expire every 90 days.
- To reset, ask the Master to raise a reset request in the IT ticket system. The reset takes up to 24 hours
  because it is processed by the shore IT team in Mumbai.
- Never share passwords over radio or write them on the bridge.
